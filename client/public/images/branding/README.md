# Branding assets

Official Lead Vest Foundation logo, cut from the supplied artwork (transparent PNG).

- `logo-mark*.webp`, `logo-wordmark*.webp`: the symbol and the name, animated separately by `components/brand/Logo.tsx`.
- `*-light.png`: same artwork with the navy turned white, for dark backgrounds.
- `logo-full*.webp`: the complete horizontal logo as one image.
- `favicon-32/64.png`, `apple-touch-icon.png`, `icon-512.png`: icons.

Paths are set in `client/src/config/brand.ts`.
